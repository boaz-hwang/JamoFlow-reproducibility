# Phase 3 addendum: autoregressive encoding-validity stress

> 상태: **Phase 3 generation 결과 전에 고정**  
> 고정 시점: 2026-08-10  
> 선행 문서: [Phase 2 generation protocol](./20-generation-validity-addendum.md), [Phase 2 generation results](./21-generation-validity-results.md), [Phase 3 protocol](./22-phase3-confirmatory-protocol.md)  
> 후속 결과 전 보강: [generation provenance](./41-phase3-generation-provenance-addendum.md)
> 주의: 이 addendum을 작성할 때 Phase 3 seed 1,729의 F 학습만 끝났고 C/W 비교와 Phase 3 generation은 없었다.

## 1. 목적

Phase 2의 1.25M model은 128-byte unconstrained continuation의 strict UTF-8 validity가 약 28–45%에 그쳤다. W 특유의 추가 악화는 중단선에 걸리지 않았지만, 이 결과로 생성 모델 품질을 주장할 수 없었다.

Phase 3에서는 더 큰 19.6M model과 128M Korean training bytes에서 다음을 다시 묻는다.

> 같은 checkpoint seed와 held-out prompt에서 F/C/W의 autoregressive output encoding failure가 어떻게 달라지며, failure가 illegal byte transition인지 terminal incomplete scalar인지?

이는 semantic generation benchmark나 latency benchmark가 아니다.

## 2. 고정 source와 prompt

1. Phase 3 HPLT3 `test` stream을 `byte_limit=16_000_000`, `sequence_length=512`로 재구성한다.
2. 각 row의 첫 256 bytes를 candidate로 삼는다.
3. row position 0과 256이 global UTF-8 codepoint boundary여야 한다.
4. prompt는 strict UTF-8이어야 하고 alphabetic codepoint 중 precomposed Hangul 비율이 80% 이상이어야 한다.
5. exact duplicate를 제거하고 prompt bytes SHA-256 순으로 처음 256개를 고른다.
6. candidate가 부족하면 기준을 완화하지 않고 실패 처리한다.

Prompt, prompt hash, source row index는 저장하지 않는다. Candidate/unique/selected count만 기록한다.

## 3. Model과 policy

- prompt: 256 bytes
- continuation: 256 bytes
- fixed horizon: 512 bytes
- policies: F `fixed_byte_6`, C `causal_codepoint_grid`, W `causal_whitespace_grid`
- initial seeds: 1,729 / 2,718 / 31,415
- Gate I 뒤 confirmation checkpoint가 생성되면: 57,721 / 65,537 추가

각 step에서 관측된 full prefix만으로 patch matrix를 다시 만든다. C/W는 `sequence_length=512`, `patch_count=86`, `require_complete=False`를 사용한다. Future generated byte는 현재 boundary에 관여하지 않는다.

HF BLT의 open-patch cache equivalence가 검증되지 않았으므로 `use_cache=False`로 full prefix를 재계산한다. 실행 시간은 기록하되 incremental generation latency나 efficiency evidence로 사용하지 않는다.

Checkpoint는 training report의 model spec, seed/policy identity, trained state SHA-256과 일치해야 한다.

## 4. Decoding

각 policy·seed·prompt에서 두 경로를 실행한다.

- greedy argmax
- temperature 0.8, top-p 0.95 sampling

Sampling은 Phase 2와 같은 CPU float64 구현, tie break, prompt별 PCG64 stream을 사용한다. 같은 seed/prompt rank는 policy 간 common random numbers를 쓴다.

대표 seed 1,729에서는 모든 policy/mode에 UTF-8 DFA hard-mask control도 실행한다. Horizon 안에서 scalar를 닫지 못하는 lead byte까지 금지하며 256/256 strict-valid가 아니면 구현 실패다. Hard mask는 model quality method가 아니다.

## 5. 고정 aggregate metric

Raw prompt와 continuation을 저장하지 않고 다음만 기록한다.

1. strict UTF-8 valid continuation rate
2. U+FFFD-free rate
3. broad conjoining-Jamo transition-valid rate
4. strict-valid continuation의 bytes/codepoint 평균·중앙값
5. UTF-8 failure taxonomy
   - strict valid
   - illegal byte transition
   - transition은 legal하지만 horizon에서 scalar incomplete
6. illegal byte가 처음 나온 zero-based continuation position의 평균·중앙값
7. legal-transition prefix bytes와 continuation fraction의 평균·중앙값
8. 마지막으로 완결된 codepoint까지의 closed-prefix bytes와 fraction
9. 실행 시간은 diagnostic only

Prompt는 codepoint boundary에서 끝나므로 continuation 자체의 strict decode와 prompt+continuation DFA closure가 일치해야 한다. 두 판정이 다르면 구현 실패다.

[Moon et al. (2026)](https://arxiv.org/abs/2606.14122)은 binary UTF-8 validity의 취약성을 지적하고 DFA 기반 partial-credit metric을 이미 제안했다. 따라서 위 failure taxonomy나 prefix metric을 본 연구의 신규 기여로 주장하지 않는다. 여기서는 exact published `V_partial`을 근사해 이름만 빌리지 않고, 더 단순한 두 관측량을 명시적으로 분리한다. `legal-transition prefix`는 incomplete scalar를 허용하고, `closed-codepoint prefix`는 마지막으로 완결된 scalar까지만 센다.

## 6. 분석

Initial 3 seeds와, 존재할 경우 final 5 seeds를 별도로 집계한다.

- policy/mode별 mean, standard deviation
- W−C, W−F, C−F seed-paired difference와 paired-t 95% interval
- failure category count/rate
- hard-mask invariant

별도 pass/fail gate를 추가하지 않는다. Phase 3 method/scale 판단은 natural-text Gate I/J/K만 따른다. Generation 결과가 약하면 “teacher-forced BPB observation은 자유 생성 신뢰성을 보장하지 않는다”는 limitation으로 보고한다.

## 7. 해석 guardrail

1. 256-byte sequence validity는 길이 의존적이며 token/character error rate가 아니다.
2. UTF-8 validity는 fluency, factuality, coherence가 아니다.
3. Hard mask 100%는 constraint 구현의 자명한 결과이지 model 향상이 아니다.
4. Full-prefix wall time은 production latency가 아니다.
5. Jamo-transition metric은 broad structural validator일 뿐 현대 한국어 형태·음운 문법 평가가 아니다.
6. 생성 sample을 공개하지 않으므로 semantic quality는 이 실험에서 판단하지 않는다.
