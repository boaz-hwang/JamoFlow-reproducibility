# Exact speculative W72 E2E preflight protocol

> 봉인일: 2026-08-13
>
> 상태: **actual speculative timing 전 seal**

## 1. 목적

Inference-mode perfect-draft target block kernel은 61.014% micro reduction과 44.044%
whole-path upper bound를 보였다. 이제 frozen independent head, mismatch correction, cache crop,
UTF-8 mask와 stop logic을 모두 실행한 실제 W72 generation이 의미 있는 wall-time 개선을
내는지 판정한다.

이 단계에서 새 head를 학습하거나 acceptance threshold를 고르지 않는다. W72 seed 1729와
generic independent head seed 20260813을 그대로 사용한다.

## 2. Exact verifier

Runtime은 target output을 바꾸지 않는다.

1. Current target logit의 strict-UTF8-masked greedy byte `b1`을 확정한다.
2. `b1`이 scalar boundary의 `EA..ED` lead일 때 head가 valid same-lead Hangul
   continuation `d2,d3`를 제안한다.
3. Target이 `[b1,d2,d3]`를 한 3-byte block으로 실행한다.
4. `d2` mismatch면 encoder/decoder/global caches, open-patch states와 selector를 `b1`
   직후로 crop하고 target correction `b2`를 확정한다.
5. Independent head가 이미 계산한 third logits를 corrected `b2`의 valid-Hangul prefix로
   다시 제한해 `d3'`를 만들고 `[b2,d3']` 2-byte retry block을 검증한다. 새 head forward는
   없다.
6. 둘째 byte/third byte mismatch에는 해당 target correction을, full accept에는 verifier
   bonus byte를 확정한다.
7. 종료 시 ordinary AR과 똑같이 마지막 emitted byte 하나가 cache보다 앞서는 invariant를
   유지한다.

Rollback은 cache length만 자르는 것이 아니다. Patch boundary별 global state, 아직 닫히지
않은 local-encoder states, UTF-8-aware W72 selector를 verified prefix와 일치하게 복원한다.
Tiny CPU에서 0/1/2/3-byte rollback을 모두 sequential runtime과 비교했고, actual W72의
16 calibration prompts에서도 2,062 generated bytes와 final cache trace가 exact였다. 이
수치는 protocol 개발 진단이며 timing 결과가 아니다.

## 3. Case와 timing

- calibration-only model-free Hangul-heavy prompts 128개
- prompt 128 bytes, output 128--131 bytes에서 첫 strict UTF-8 boundary
- acceptance preflight에 이미 봉인한 prompt set을 source stream에서 독립 재구성
- repetitions: prompt당 3회; repetition은 독립 표본으로 세지 않음
- mode order: prompt×repetition parity로 baseline/speculative 정확히 균형
- head와 proposal tables는 두 mode 모두에서 resident
- timer scope: fresh runtime, parallel prefill, 전체 greedy decode, head, target block,
  rollback/correction/bonus, Python scalar readback, 마지막 MPS sync
- AC power와 shared publication MPS exclusion lock 필수

먼저 untimed pass에서 128/128 baseline/speculative output bytes와 최종 cache diagnostics가
exact인지 확인한다. Timed repetition도 그 canonical output hash와 달라지면 즉시 실패한다.

## 4. 통계와 stop rule

Prompt 안의 3 repetitions을 median으로 접은 뒤 128 prompts를 10,000회 bootstrap한다.
Seed는 20260831이다. 다음을 모두 만족해야 후속 multi-seed/generic comparator를 허가한다.

- E2E median reduction ≥20%
- prompt-bootstrap 95% lower bound ≥10%
- 128 prompts 중 최소 96개에서 reduction >0
- outputs와 caches 128/128 exact

20%/10%는 target block 결과 문서에서 actual runtime을 보기 전에 고정한 gate다. 실패하면
retry 횟수, head architecture, activation 또는 threshold를 결과에 맞춰 다시 튜닝하지 않고
multi-byte branch를 종료한다.

## 5. Claim 경계

통과해도 single target/head seed의 calibration preflight다. 다음 단계는 다섯 target
seeds에 seed-specific head를 고정하고, same-cost generic all-byte MTP와 W72 AR을 함께
비교하는 것이다. 그 비교에서 Hangul-aligned activation의 추가 E2E 이득이 없으면
한국어-specific novelty는 주장하지 않는다. 새 disjoint held-out timing 전에는 publication
efficiency result로 쓰지 않는다.
